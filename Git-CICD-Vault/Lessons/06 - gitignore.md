# Lesson 6 – The .gitignore File
⬅️ [[05 - First Repository]] | ➡️ [[07 - First Commit]]

Should we push everything? **No.**

| Path | Commit it? | Why |
|---|---|---|
| `src/` | ✅ | Your source code |
| `pom.xml` | ✅ | Maven dependencies |
| `target/` | ❌ | Generated build output |
| `.idea/` | ❌ | IntelliJ config, usually not shared |
| secrets/passwords | ❌❌ | Never commit |

```bash
nano .gitignore
```
```gitignore
# Maven
target/

# IntelliJ IDEA
.idea/
*.iml

# Logs
*.log

# Environment files and secrets
.env
.env.*
!.env.example

# OS files
.DS_Store
```

## Why it matters
Git checks `.gitignore` when deciding which untracked files to ignore. Files like `target/classes/`, `target/generated-sources/`, `target/surefire-reports/` are regenerated by:
```bash
mvn clean package
```

> [!danger] Enterprise rule
> Never commit passwords, database credentials, API keys or private certificates.
