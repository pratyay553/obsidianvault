# Flashcards: Linux Core

Format `Question::Answer`. Works with the *Spaced Repetition* community plugin (add tag `#flashcards` in plugin settings if you want it to scan only this note, or set the plugin to scan everything).

Cards are also embedded at the bottom of each concept note. This note is a mixed-review deck. #flashcards

What is `/proc`?:: A virtual filesystem generated by the kernel exposing process and kernel info.
What is stored in a directory entry?:: A name mapped to an inode number.
When is file data freed?:: When link count hits 0 and no process holds it open.
What does `x` on a directory allow?:: Traversing/entering it.
What checks does the kernel do for permission?:: Owner, else group, else others; first match wins.
Why does `sudo echo x > file` fail?:: The shell does the redirection with your privileges.
Exit code 143?:: Killed by SIGTERM (128+15).
Exit code 137?:: Killed by SIGKILL (128+9), often OOM.
Which signals cannot be caught?:: SIGKILL, SIGSTOP.
What does `daemon-reload` do?:: Makes systemd re-read unit files.
What does 203/EXEC mean?:: systemd cannot execute ExecStart.
What does 200/CHDIR mean?:: WorkingDirectory problem.
What does 217/USER mean?:: User= does not exist.
Connection refused means?:: Host reachable, nothing listening on that port.
Connection timeout means?:: No reply; dropped, unreachable, or down.
Which `free` column matters?:: `available`.
Load average vs CPU %?:: Load counts runnable and I/O-blocked tasks; CPU % is utilisation.
Why `df` > `du`?:: Deleted-but-open files and other causes.
Many CLOSE_WAIT?:: Your app is not closing sockets.
Why not `chmod 777`?:: Over-broad; hides the real ownership issue; insecure.
What does `set -u` do?:: Errors on unset variables.
Why quote variables in bash?:: Avoid word splitting and globbing.
Where does service stdout go in systemd?:: The journal.
Does After= create a dependency?:: No, only ordering.
Why use `tail -F`?:: Follows across rotation by reopening by name.
